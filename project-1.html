Ostentans

Ostentans is a resume management system that allows a user to manage their resume data, generate PDF resumes, and save them for future reference.

Problem

Job hunting typically requires tailoring a CV for each role, which often leads to dozens of nearly identical documents, nested folders, and inconsistent formatting. Candidates also have to re-enter the same information into different application portals, making it hard to quickly customise a resume for a specific job.

Solution

Ostentans solves this by centralising resume data in one place. Users capture their details once, then compose role-specific resumes from that data, generate consistently styled PDFs, and safely update or delete information without worrying about breaking previously saved resumes.

Summary

The system functions as a full resume management platform, allowing users to create, view, update, and delete personal, education, work experience, and skills records, keeping their profile current while maintaining a clean history of tailored resumes.

The resume styling was manually created by recreating the structure of ATS-friendly resumes. PDF generation is created using QuestPDF.
